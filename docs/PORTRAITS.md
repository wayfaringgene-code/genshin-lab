# 立ち絵の集め方（同梱の立ち絵）

命ノ星座カードは、キャラの立ち絵がリポジトリに入っていれば、**誰が開いても自動でカードに入れます**（利用者が自分で選んだ立ち絵があれば、そちらが優先）。
立ち絵がないキャラは、カードの真ん中に名前の頭文字が出るだけになるので、主要なキャラから順に集めるのがおすすめです。

## 1. 用意する画像

| 項目 | 条件 |
|---|---|
| 形式 | PNG か WebP（JPEG も可） |
| 背景 | **透明（キャラだけ切り抜かれたもの）**がいちばんきれい。カードの星座の中に、上半身が収まるように自動で切り出す。背景つきでも使えるが、横長の枠でそのまま貼る形になる |
| 大きさ | 長い辺が 1000px 以上あると安心（1600px より大きいものは自動で縮める） |
| 構図 | 全身か上半身。頭が切れていないもの。武器などで横に大きく広がる絵より、縦長の絵のほうが収まりがいい |

## 2. ファイル名

- **ゲーム内のキャラ名そのまま**：`フリーナ.png`、`雷電将軍.png`、`楓原万葉.png`
- 名前が同じキャラ（旅人）は **avatarId**：空は `10000005.png`、蛍は `10000007.png`
- 名前の表記は Enka.Network の日本語名に合わせる（迷ったら、カードアプリのキャラ一覧に出ている名前）
- 新キャラで名前が通らないときは、先に Enka の対応表の更新が要る（`MAINTENANCE.md` の「新キャラ・新セットが出た」）

## 3. 渡し方

1. 1つのフォルダにまとめて ZIP にする（何人分でも、少しずつでもよい）
2. Claude に渡して「立ち絵を登録して」と頼む

Claude がやること：
```
python3 tools/build_portraits.py <ZIP を開いたフォルダ>
```
- 長い辺 1600px に縮めて WebP（透明を保つ）にし、`src/portraits/{avatarId}.webp` に置く
- `src/portraits/portraits.json` に登録する（すでにあるキャラは画像だけ差し替え）
- 名前の分からないファイル・背景が透明でない画像は、一覧で知らせる
- commit・push すると、GitHub Pages に自動で反映される
- 見本のキャラ（今はフリーナ）の立ち絵を入れたら、`tools/make_og.mjs` で X 用の画像（`src/og.png`）も作り直す

## 4. 位置と大きさの調整（必要なときだけ）

自動の切り出しで顔が切れる・小さすぎるキャラは、`portraits.json` のそのキャラに値を足すと、全員の初期値が変わる。

```json
"10000089": { "file": "10000089.webp", "name": "フリーナ", "zoom": 115, "pos": { "dx": 0, "dy": -20 } }
```

- `zoom`：大きさ（%、100 が自動のまま。60〜170）
- `pos`：位置のずらし（カードの上での px。`dx` は右へ、`dy` は下へ）
- 自分のカードアプリで、立ち絵の大きさのつまみとドラッグで合わせてから、その値を Claude に伝えると早い

## 5. 権利について

- キャラクターの画像の権利は HoYoverse にある。このツールは非営利のファンツールとして公開し、アプリの中で広告や有料の機能は使わない
- 画像の出どころ（公式サイト・公式の配布物・自分で撮ったゲーム画面など）は、集めるときにメモしておく
- 権利者から求められたら、すぐに外せるようにしておく（`src/portraits/` から消して push するだけ）
- 同梱の立ち絵は GitHub Pages 版だけで使う（claude.ai の artifact 版では使わない）
