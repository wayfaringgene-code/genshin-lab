基本の機能（ホーム → UID → いちばんすごいカード → 共有）は v2.0 でそろった。ここからは「最初の印象」と「広めること」に効く順に進める。
新しいスレッドで続けるときは、このファイルと `MAINTENANCE.md` を読んでから始める。

## 2. ガチャふうの演出（v2.1 で公開。案2 落ちるカード）

立ち絵が何人か入ってから作る（見せ場は「カードが表に返って立ち絵が出る瞬間」）。動きの試作を2〜3案作って見比べてから仕上げる。

差し込む場所：`tools/build_card.py` の `homeReveal(names)`（UIDで取り込んだあと、いちばん秘境レベルが高いキャラのカードを出している所）。

**決めた思想（2026-10-28）**：お気に入りのキャラのカードが、自分のものとして形になる瞬間を祝う。射幸心は煽らない。
- 祝う順：①このキャラのカードが手に入ること（愛着）＞②秘境を回った日々が形になること＞③数字の珍しさ
- 全員を同じ儀式で迎える。ランクの差は色と★の数（★1〜★5、★5+ は★5＋「＋」、100年超えは虹の★）。いちばんのカードだけ、溜めを少し長く、光を少し強く
- 見せ場は縦動画（9:16、SNS用）。アプリの中ではスキップされる前提。動画は「1枚」（好きなカードを1枚）と「全員」の2種類
- 揺れは使わない。原神本家の祈願演出には似せない

**進み具合**：試作の3案を `build_card.py` に入れた（本番の流れは仮に案2）。1080×1920 のキャンバスに時刻だけから1コマを描く作りなので、縦動画の書き出しも同じ描き方でできる。トップのURLの末尾に `#reveal` を付けると、見本のキャラで流せる操作盤が出る（案・全員/1枚・人数・最後のランク）。`?reveal=drop`（photo・foil）で、UIDで取り込んだときの案を切り替えられる。
- 案2 落ちるカード（drop）：はじめカードは画面の外（カメラより上）にあり、机にはぼやけた影だけが落ちて、近づくほど濃くくっきりしていく。最後の0.2秒で一気に落ち、落ちるあいだは逆光で表が少し暗く、縁だけが金に光る（暗くしすぎるとカードに見えない）。着地で光の風圧が広がって机の星屑を押し流し、カードの表が中央から灯る。全員のときは、少しずつ角度を変えて机に重なっていく。いちばんのカードだけ影の時間が長い。その間、名前の位置に「最後の1枚」と出し、机の星屑が落ちる場所へ吸い寄せられ、落ちる場所の机からランク色の光が漏れて、ドクン、ドクンと2回脈打ってから最大になる（ただ暗く待たせると「謎の時間」に見えるため）。着地は真ん中にまっすぐ
- 机（背景）：夜空を映した黒い漆の天板を真上から見下ろす。紺の地に左上からの照り返しと斜めのつや、映り込んだ星、左下と右上の隅から流れ込む金粉（蒔絵）。カードの下には、天板に映ったカードが上下逆さに薄く出て、落ちてくるあいだは離れていて、着地で縁に合う（初めは暗すぎて、机に見えていなかった：平均の明るさ 17/255 → 27/255）
- テンポ（案2・案2'）：いちばんのカードの直前の1枚までは同じ駆け足（1枚あたり約0.65秒）、直前の1枚だけ0.7倍に落として溜めにつなぐ。いちばんのカードの着地は 3人 4.4秒／6人 6.3秒／8人 7.6秒／12人 10.1秒（溜めを2.0秒にしたあと）（一律1.7秒だと12人で20.7秒かかり、長すぎた）
- 最後の1枚の溜め（案2）：見てほしいのは直前のカードではなく「これから降りてくる場所」。直前のカードの表面を横切る光沢は、目がそのカードに行ってしまうのでやめた。代わりに A スポットライト（落ちる場所に真上から光が差し、まわりが沈む）と B 天板に灯る星座（そのカードの星座＝5部位の星が、鼓動に合わせて1つずつ灯って線でつながり、落ちてきたカードの星座とぴたりと重なって着地、着地で外へはじける）。どちらもランクに関係なく同じ。試作の操作盤で A／B／A＋B を切り替えられる（本番は仮に A＋B）。溜めは2.0秒。溜めのあいだ机のカードをだんだん深く沈め、天板の星座ははじめ1.3倍で灯って中心へ集まり、着地の瞬間にカードの星座の大きさに収まる（下のカードの星座と二重に見えないように）
- 案2' 舞い降りる写真（photo）：白い縁の写真が、ヒラっと一度だけ揺れて舞い降りる。風圧は軽く、いちばんのカードは波紋が二重
- 案3 箔押し（foil）：紙送りで入った無地のカードがプレスされ、型押しの凹凸 → 色 → 名前と数字に金の箔（光が横切る）→ ★を印のように押す。いちばんのカードは光の版で溜めてから、箔押しが2度押し
- アプリの中の操作（2026-10-28 に決定・実装）：自動で進むのが基本。画面を押す（Enter・スペースでも）と次のカードへ（いちばんのカードの溜め中なら落ちる瞬間へ、着地のあとなら締めへ）。右上の「スキップ」（Esc）で最後へ。設定の「カードの登場の演出」でオフにでき、一覧の下の「次から演出を出さない」でもオフにできる
- 演出のあと：全員のときは、最後の画面で押すと、机に重なったカードがそれぞれの位置・角度・大きさから、一覧の自分の場所へ滑って広がる（上のカードから順に。机は裏でゆっくり溶ける。暗転しない）。一覧は「取り込んだカード」で、秘境レベルの高い順、いちばんのカードは金の枠と「いちばん」の札。カードを押すと、そのカードのページが開く。自動では一覧へ移らない（最後の画面の余韻を残す）
- 始まるまでの間：カードの絵（書体を埋め込んだ画像）を作るのに、以前は全員ぶんを待って2〜3秒かかっていた。いまは出てくる順に2枚ずつ用意し、最初の1枚ができたら流し始める（0.4〜0.5秒）。間に合わないカードがあれば、そのカードの手前で待つ
- 一覧のあと：「カードのページへ」で、いちばんのカードのページを開く（一覧のカードを押せば、そのカードのページ）。カードのページは ◀ ▶ で全員を見られ、1枚ずつの保存（PNG・WebP）・共有に加えて「全員をまとめて保存」（ZIP）を置いた
- 縦動画：「全員」の動画は4〜6枚に絞る。どのカードを入れるかは、動画を作るときに作り手が決める。一般の人の画面には選ぶ仕組みを出さない（作り手だけが使う隠しの入口にする）
- 2026-10-30：案2（溜めは A＋B）に決め、案2'・案3と切り替えの仕組みを消して v2.1 として公開。#reveal の操作盤は「見本で流す」として残した（作り手の確認用）

アイデア（叩き台）：
- 10連ふうの順番：取り込んだキャラを秘境レベルの低い順にめくり、いちばんすごいキャラを最後に出す。スキップのボタンを付ける
- 最後の1枚の前に、ランク色の光で匂わせる（★1〜★5+ の色はカードと同じ。100年超え・5000年超えは虹）
- 見た目は「命ノ星座」らしいオリジナルに：星が1つずつ灯って線でつながり、星座が完成するとカードが表に返る。**原神本家の祈願演出（流れ星・光の玉など）はそっくりにしない**
- 端末で「視差効果を減らす」などを選んでいる人には、短い演出にする

## 2.5 カードの作り方と保存の整理（v2.2 で公開）

2026-10-30 に決めた形：
- UIDで取り込んだキャラ（ショーケース。普通は選りすぐりの推しキャラ）は「一期一会」。キャラ一覧に入れず、ホームにカードで並べる。いつも最後に取り込んだキャラだけ。履歴なし・引っ越しなし・ラボからは見えない。立ち絵と位置はUIDのカード用に別に持つ（意図しないときに、別のカードの立ち絵が動かないように）
- それ以外（動画・スクショ・手入力・引っ越し）はキャラ一覧へ。行の「カードを作成」で、カードのページにそのキャラのカードを1枚だけ出す
- 有効OPは「名前＋セット」ごとに1つ。4セットはセット名、2セット＋2セットは2セット効果の組み合わせ（「攻撃力+18%＋攻撃力+18%」）で見分け、表示もこの形（2セット効果の表は `tools/set_bonus.json`、`tools/build_set_bonus.py` で作る）。セット名が空欄のキャラは「名前だけ」で1つ
- キャラの編集とスクショの取り込みの確認では、セットを選ぶ（なし／4セット／2セット＋2セット／2セットだけ）
- まだのこと：スクショからセット名を自動で読む（いまは選ぶ）。旅人は元素ごとに別のキャラとして数える（いまは名前だけで見分けている）

## 2.6 スマホで見やすい2種類目のカード（次のスレッドの本題）

2026-10-30、スマホで何度か使ってみての気づき：小さい画面だと、どこを見ればいいかが定まらない。
既存のビルドカード（各部位がS以上か、合計スコアが200以上か）は、見る場所と合格ラインが決まっているので一目で分かる。

**決めたこと**
- 今のカード（星座カード）は気に入っているので残す。新しいデザインは「2種類目のカード」として作り、保存・共有のときにどちらかを選べるようにする
- 2026-10-31（思想）：
  - 部位と全体の両方を見せる（ビルドカードで、どの人にもなじみのある見方）。主役は★（全体の★と5部位の★）、数字（か月）は裏付け
  - 合格ラインは作らない。今の★の区分け（★1〜★5+、百年級）を物差しにして、どこで満足するかは見る人に任せる（「★4で十分」「SNSなら★5+でないと驚かない」は人それぞれ）
  - 今回いちばん見せたい相手は、SNS で流れてきた人。★5+・百年級がひと目で「おっ」となること。★1〜★3も恥ずかしくない落ち着いた見た目に
  - 雰囲気は星座カードから大きく外さない。夜空・星・金の宇宙っぽさを引き継ぐ（五角形のチャートはやめる）
  - 原神ラインは保留（ほかの部分が組み上がってから）
  - 試作で確かめること：秘境レベルを知らない人向けの一言（例：「秘境だけで揃えるのに、平均41か月」）を載せるか。単位を「か月」にそろえるか（★の境目が 1・3・12・36か月 と並ぶ）
- 2026-10-31〜11-12（1回目の試作のあとで）：
  - **サブOPは必須**。ないと実感が湧かず眉唾に見える。サブOPの値そのものも SNS で自慢する材料
  - 方向は「今のカードの右側（サブOPつきの5行）を主役にする」。五角形を外し、行の右端の小さな物差し（★の段で区切った棒）を大きくする

**1回目の試作（ブランチ `card2-proto`。`main` には入れていない）**
- `tools/build_card.py` の「2種類目のカード（試作）」。トップのURLの末尾に `#card2` で開き、A〜D と今のカードを切り替えて見られる（見本のキャラ・UIDのショーケース・キャラ一覧。単位と一言の切り替えつき）。縦長 4:5（1080×1350）、見出しの右上に立ち絵
  - A 一列に灯る星／B 段の横棒／C 五角形（目盛りを★の段にした改良版）：どれもサブOPなしで作ってしまい、前提がずれていた
  - D 今のカードの右側を主役に：左に部位・メインOP・★と数字、右に★の段の棒とサブOP 4つ（2×2）。いちばん解に近いが、見た目はまだ使えない（下の違和感）
- 見本のキャラ（スカーク）は開くたびにランダムに作るので、案どうしを同じデータで比べられない。次は決まった見本で比べる

**分かったこと**
- 今のカードは、左の五角形が右の5行の言い直しになっている（部位の秘境レベルが2回、部位のランクが3〜4回、★の段の区切りが2回）。五角形にしかない情報は「5部位の釣り合い」だけ。ただし左半分は立ち絵の置き場でもある
- 五角形の中心からの距離は「★の段ごとに同じ幅」の目盛り（純粋な対数ではない）。面積で目に入る五角形と、対数に近い目盛りは相性が悪い。対数の物差しは「段（何段目か）」で見せると分かりやすい
- 「か月」は★5+（36か月〜）までは読みやすいが、百年級では `18,981 MONTHS` のように桁が多すぎて破綻する。百年を超えたら YEARS に切り替えるか、★と「ONCE IN A CENTURY」だけで見せるかを決める

**持ち主の「1秒テスト」での違和感（数週間ぶりに D を見て。2026-11-12）**
最初の1秒の感想は「どこを見ればいいんだっけ」「このカードってすごいの？」
1. ★5 を最初に見せたいなら、強調が足りない（視線の順番）
2. ランクの色を全部に使っていて、色が飽和している（差し色は少ない場所にだけ）
3. 「★★★★★」と「★5」の表記がぶれている（表記の一貫性）
4. 「22 MONTHS」が★の列に近すぎ、色も同じで見えなくなっている（違うものは離すか、色を変える）
5. サブOPの主張が強くて、大事なゲージに目がいかない（主役と脇役の強さの差）
6. 行の中の「★5+」と「43 MONTHS」の、どっちを見ればいいか分からない（1つの場所に主役は1つ）
7. 「★5+」が MAX なのか、もっと上があるのか分からない（物差しの上限を見せる。実際は上に百年級・有史以来がある）

**Claude の反省（このスレッドから）**
- 今のカードの中身の棚卸し（何が言い直しで、何がそこにしかないか）を最初にやらずに、新しい形を一から作った。サブOPを聞かずに外した。「今のカードから言い直しを削る」という素直な道を、持ち主に言われるまで見落とした
- 「SNS向け＝情報を減らす」と思い込んだ。原神の人が SNS で何を見て「すごい」と思うかを聞かなかった
- 返事が長く、選択肢が多く、ブランチや push の話で本題の時間を食った
- 試作を持ち主のスマホで触ってもらう前に、画像だけで判断を進めた。見せる前に、自分の絵を基本の決まりで点検していなかった（上の7つの大半はそこで拾えた）

**次のスレッドの進め方（2026-11-12 に決めた）**
1. 絵を描く前に、視線の順番を言葉で決める（例：1秒目は全体の★だけ／2秒目は5部位のゲージ／3秒目はサブOP、読みたい人だけ）
2. 決まりを先に作る：ランクの色は2か所までしか使わない。★の表記は1つにそろえる。1か所に主役は1つ。物差しには上限（百年級）まで見せる
3. Claude は、見せる前にその決まりで自分の絵を点検する。返事は短く、問いは1回に1つか2つ
4. 持ち主は「1秒テスト」をする（少し間をおいてカードを見て、最初の1秒で思ったことを書く）。試作は早めに `main` の隠し入口（`#card2`）に入れて、持ち主のスマホと自分のUIDで触れるようにする
5. 土台は D。新しい形を一から作らず、今のカードから言い直しを削る方向で直す

**活路を感じたアイデア（持ち主から）**
1. 秘境レベルの単位を「か月（MONTHS）」に統一する。100年級は「1,200か月」のように数字が大きくなるので、桁区切りなど読みやすさの工夫が要る
2. 部位別の評価（★5など）を分かりやすく。いまは部位ごとの日数が主役で、★は小さな物差しの中。★（またはS・SSのような段位）を部位の主役にすると、ビルドカードの「各部位がS以上か」に近い見方ができる
3. 五角形のチャートは、スマホでは分かりにくい。5本の横棒や、5つの★の札などに置き換える案
4. 原神のリリース日（2020-09-28）から計算した「ここを超えたらマジ凄いライン」を設ける。リリースの日から毎日秘境を回り続けた日数＝2026-10-30 時点で約2,223日（約73か月・約6.1年）。「原神が始まった日から毎日回っても、まだ届かない」という線で、日がたつごとに少しずつ伸びる

**進め方の案**
- 思想（何を一目で伝えるか、合格ラインは何か）を先に言葉で決める → スマホの幅で、見た目の試作を2〜3案作って見比べる → 仕上げ（演出・ショーケース・保存・共有にも、2種類目のカードを通す）
- 試作は、見本のキャラ（`#reveal` の操作盤と同じ作り方）か、自分のUIDで見られるようにする

## 2.7 聖遺物一覧と育成候補（相談中。2026-11-12）
- 動画で読んだ聖遺物のうち、いまは装備中の分しか使っていない（`src/scanner/core.js` の `toLab`）。装備していない分を「手持ち」として別に保存し、聖遺物一覧のタブと、キャラ一覧の棒を押したときの育成候補に使う
- 手持ちは動画でしか作れない（UID・スクショでは手に入らない）。GOOD 形式には1個ごとのIDがないので、動画を読むたびにまるごと入れ替える。日付を出し、キャラのほうが新しければ知らせる
- 決めたこと：手持ちはまるごと入れ替え／棒を押すと候補、札を押すとカード／ほかのキャラが装備中の1個も候補に入れる（「◯◯が装備中」。相手が下がる分も出す）／4+1も候補に入れる
- 候補の計算は「1個を評価」と同じ（いまの部位を超える確率・平均の伸び）。超える確率0%は出さない
- キャラごとの方針は「遊ぶ人の判断（端末に保存）」→「このアプリの初期値（`src/builds.csv`、docs/BUILDS.md）」→「装備からの推測」の順で使う
- 表のメインOP（砂・杯・冠、複数可）は**候補の絞り込みだけ**に使う。カードの秘境レベルは、いままでどおり実際に付けている1個のメインOPで計算する（「どちらでもいい」にすると当たりの確率が上がって日数が短く出てしまい、遊ぶ人同士で比べにくくなるため）
- 2026-11-12：2.6（2種類目のカード）より先に、こちらを進めることにした
- 試作1回目（2026-11-12）の反省：聖遺物のページで1個ごとに「伸びの大きい順」に候補のキャラを出すと、部位が空いている・育てていないキャラ（イルーガなど）が「ほぼ100%・+590%」で上を占め、実用的でなかった
- 試作2回目で決めたこと：
  - 聖遺物のページは「育てる」が主役。1個ごとに、**そのセットを4セットで使うキャラ**（初期値の表の「使えるセット」。メインOPも合うもの）を全員並べ、それぞれ「いまの部位を超える確率」を添える（0%のキャラも「いまのほうが上」と出す）
  - 2＋2・「どれでも」・使えるセットが空欄のキャラは並べない（表に4セットで書いたキャラだけ）。表の「使えるセット」が、そのまま「このセットで育てるキャラ」の登録になる
  - 4+1 は聖遺物のページでは出さない。キャラ一覧から開く育成候補では「ほかのセットも出す（4+1）」で出せる（初めの状態は表の「4+1」の列）
  - ページの並びは「素質」＝+20まで上げたときの平均の有効RVが秘境で何日分か（使うキャラの有効OPで測り、いちばん高く出る分）
  - 公開する前に：遊ぶ人が自分の端末で「使えるセット」を足したり外したりできる調整弁を付ける（有効OPと同じ扱い。基本はアプリの初期値で足りる想定）
  - 「手持ち最強ランキング」（+20の秘境レベル順）はカードのほうの題材として後で考える（2.6 と合わせて）
  - ダメージの見積もり（試作、2026-11-13）：「この1個に替えたら、基準の技のダメージが何%変わるか」。ダメージの値そのものは求めない（天賦倍率・耐性・防御は比べると消える）
    - いまはフリンズ（雷霆のシンフォニー＝月感電の直接ダメージ）だけ。条件は Lv90・無凸・モチーフ武器R1・月兆は昇輝・天穹4セット。ベネットのバフ（天賦13、基礎攻撃力674の武器）は聖遺物のページで切り替え
    - 式：攻撃力×(1＋基礎ボーナス：攻撃力100ごと0.7%、上限14%)×(1＋6×熟知÷(熟知＋2000)＋反応ボーナス)×会心。熟知は攻撃力の8%（上限160）が足される
    - 照らし合わせ：数字は genshin-db 5.2.15、式は gcsim（b107b5d、2026-11-09）の実装と一致を確かめた（固有天賦の+20%は直接ダメージにも乗る、武器の+36%も同じ、天穹4セットは会心率+30%と月反応+10%）
    - +20までの伸び方は、強化が4行に入る回数の組み合わせごとに数える（伸び幅は平均）。会心率100%の上限のような折れ曲がりがあるので、平均の伸びを足すだけの見積もりより正確
    - 次：ほかのキャラに広げるなら、キャラごとに基準の技と式を決める（マーヴィカの溶解など）
  - 宿題：聖遺物のページ（素質＝秘境何日分の順）と、キャラ一覧から開く育成候補（有効RVの平均の伸びの順）で、並びのものさしが違う。あとでアプリを分けるか、完成したページの方式にそろえる
  - キャラの札の吹き出し（マウスを載せたとき）：部位の秘境レベルとスコアを「いま／+20で平均／+20で最大」の表で出す。最大は、秘境レベルは残りの強化がすべて有効OPに最大の伸びで入ったとき、スコアはすべてスコアにいちばん効く行に最大の伸びで入ったとき（別々に計算）。スマホでは吹き出しは出ず、札を押して開く育成候補の画面に同じ情報を出す
- 進め方：初期値の表を整える（29人を見直し済み） → 試作専用の artifact（本番と保存場所が別）で触って確かめる → main に入れて公開

## 3. 縦長の動画（Shorts・X 用）の書き出し

演出が固まってから。演出をそのまま 9:16 の動画（mp4 か webm）に書き出し、最後にアプリ名とURLを入れる。保存は downloads（mp4・webm に対応）と、GitHub 版では普通のダウンロード。

## 4. 公開前の仕上げ

- ホームの飾り付けの磨き込み、立ち絵入りの見本で OGP 画像の作り直し
- （任意）Cookie を使わない無料の計測（Cloudflare Web Analytics など）で、来た人数・カードまでたどり着いた人数を見る
- X で軽く公開

- 友達のUIDとの比較
