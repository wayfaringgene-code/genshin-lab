# これからの予定（2026-10-28 に決めた進め方）

基本の機能（ホーム → UID → いちばんすごいカード → 共有）は v2.0 でそろった。ここからは「最初の印象」と「広めること」に効く順に進める。
新しいスレッドで続けるときは、このファイルと `MAINTENANCE.md` を読んでから始める。

## 1. 今すぐ並行して（持ち主の作業が中心）

- **立ち絵集め**：手順は `docs/PORTRAITS.md`。全員そろうのを待たず、集まったぶんから ZIP で渡して登録する。10〜20人入るだけでも初見の印象が大きく変わる
  - 優先の目安：自分のショーケースのキャラ → 最近の★5 → 人気キャラ
  - 最近の★5（新しい順、2026-10-28 時点の Enka の対応表より）：オデット、ヴェスナ、ヴォジャニーツァ、サンドローネ、ニコ、リンネア、ローエン、ファルカ、兹白、コロンビーナ、ドゥリン、ネフェル、フリンズ、ラウマ、イネファ、スカーク、エスコフィエ、ヴァレサ、夢見月瑞希、シトラリ
  - 見本のキャラ（フリーナ）の立ち絵が入ったら、`src/og.png` を作り直す
- **スマホでの実機確認**：共有ボタン（共有シート）、X にURLを貼ったときの見え方、ホームからの流れ。気になった所はその都度直す

## 2. ガチャふうの演出（次のスレッドの本題）

立ち絵が何人か入ってから作る（見せ場は「カードが表に返って立ち絵が出る瞬間」）。動きの試作を2〜3案作って見比べてから仕上げる。

差し込む場所：`tools/build_card.py` の `homeReveal(names)`（UIDで取り込んだあと、いちばん秘境レベルが高いキャラのカードを出している所）。

**決めた思想（2026-10-28）**：お気に入りのキャラのカードが、自分のものとして形になる瞬間を祝う。射幸心は煽らない。
- 祝う順：①このキャラのカードが手に入ること（愛着）＞②秘境を回った日々が形になること＞③数字の珍しさ
- 全員を同じ儀式で迎える。ランクの差は色と★の数（★1〜★5、★5+ は★5＋「＋」、100年超えは虹の★）。いちばんのカードだけ、溜めを少し長く、光を少し強く
- 見せ場は縦動画（9:16、SNS用）。アプリの中ではスキップされる前提。動画は「1枚」（好きなカードを1枚）と「全員」の2種類
- 揺れは使わない。原神本家の祈願演出には似せない

**進み具合**：試作の3案を `build_card.py` に入れた（本番の流れは仮に案2）。1080×1920 のキャンバスに時刻だけから1コマを描く作りなので、縦動画の書き出しも同じ描き方でできる。トップのURLの末尾に `#reveal` を付けると、見本のキャラで流せる操作盤が出る（案・全員/1枚・人数・最後のランク）。`?reveal=drop`（photo・foil）で、UIDで取り込んだときの案を切り替えられる。
- 案2 落ちるカード（drop）：はじめカードは画面の外（カメラより上）にあり、机にはぼやけた影だけが落ちて、近づくほど濃くくっきりしていく。最後の0.2秒で一気に落ち、落ちるあいだは逆光で表が少し暗く、縁だけが金に光る（暗くしすぎるとカードに見えない）。着地で光の風圧が広がって机の星屑を押し流し、カードの表が中央から灯る。全員のときは、少しずつ角度を変えて机に重なっていく。いちばんのカードだけ影の時間が長い。その間、名前の位置に「最後の1枚」と出し、机の星屑が落ちる場所へ吸い寄せられ、落ちる場所の机からランク色の光が漏れて、ドクン、ドクンと2回脈打ってから最大になる（ただ暗く待たせると「謎の時間」に見えるため）。着地は真ん中にまっすぐ
- テンポ（案2・案2'）：1枚目はふつうの速さ（約1.7秒）で儀式の形を見せ、2枚目は0.75倍、3枚目からは0.4倍の駆け足、いちばんのカードの直前の1枚で0.7倍に落として溜めにつなぐ。いちばんのカードの着地は 3人 4.9秒／6人 7.7秒／8人 9.1秒／12人 12.1秒（一律1.7秒だと12人で20.7秒かかり、長すぎた）
- 案2' 舞い降りる写真（photo）：白い縁の写真が、ヒラっと一度だけ揺れて舞い降りる。風圧は軽く、いちばんのカードは波紋が二重
- 案3 箔押し（foil）：紙送りで入った無地のカードがプレスされ、型押しの凹凸 → 色 → 名前と数字に金の箔（光が横切る）→ ★を印のように押す。いちばんのカードは光の版で溜めてから、箔押しが2度押し
- 決まったら、残りの案と操作盤を消し、縦動画の書き出し（「1枚」「全員」）を作って、版を v2.1 にする

アイデア（叩き台）：
- 10連ふうの順番：取り込んだキャラを秘境レベルの低い順にめくり、いちばんすごいキャラを最後に出す。スキップのボタンを付ける
- 最後の1枚の前に、ランク色の光で匂わせる（★1〜★5+ の色はカードと同じ。100年超え・5000年超えは虹）
- 見た目は「命ノ星座」らしいオリジナルに：星が1つずつ灯って線でつながり、星座が完成するとカードが表に返る。**原神本家の祈願演出（流れ星・光の玉など）はそっくりにしない**
- 端末で「視差効果を減らす」などを選んでいる人には、短い演出にする

## 3. 縦長の動画（Shorts・X 用）の書き出し

演出が固まってから。演出をそのまま 9:16 の動画（mp4 か webm）に書き出し、最後にアプリ名とURLを入れる。保存は downloads（mp4・webm に対応）と、GitHub 版では普通のダウンロード。

## 4. 公開前の仕上げ

- ホームの飾り付けの磨き込み、立ち絵入りの見本で OGP 画像の作り直し
- （任意）Cookie を使わない無料の計測（Cloudflare Web Analytics など）で、来た人数・カードまでたどり着いた人数を見る
- X で軽く公開

## 5. 「また来る」ための機能（反応を見てから）

- 前回からの伸び（取り直したときの変化。履歴の仕組みはある）
- 友達のUIDとの比較

## 後回しでいいもの

- ラボとカードの共通部分の切り出し、ラボに残っている「空の部位がメインOPつきで保存される」不具合
- 中継の呼び出し回数の制限（必要になったら）

## 発信先のメモ

- X：カード画像の共有の主戦場（OGP・共有ボタンはここに合わせてある）
- YouTube：長い動画は使い方や考え方（秘境レベル、五分五分のラインの証明など）、カードが出る瞬間は Shorts
- インスタは後回し（縦動画を広げるなら TikTok のほうが合いそう）
