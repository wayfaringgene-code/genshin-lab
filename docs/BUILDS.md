# 育成の方針の初期値（`src/builds.csv`）

キャラごとに「どの聖遺物を育てる候補にするか」を決める表。**このアプリでの初期値**で、遊ぶ人同士で比べやすくするためのもの。
遊ぶ人が自分の端末で決めた有効OPがあれば、そちらが優先される。表にないキャラは、いままでどおり装備から推測する。

## アプリでの使われ方（v2.3）
組み立てのとき（`tools/build_card.py`）に表を読み込み、命ノ星座カードのページに埋め込む。書き間違いがあると組み立てが止まり、公開ページは前のまま残る。

| 列 | 使われ方 |
|---|---|
| 有効OP | 遊ぶ人が決めていないキャラに当たる（年表・カードでは「初期値」と出る）。遊ぶ人はキャラごとに上書きできる |
| 使えるセット | 育成候補（キャラ一覧の行を押すと開く）で、候補にするセットを絞る。聖遺物のページのキャラの札には、**4セットで書いたキャラだけ**が出る（2＋2・「どれでも」・空欄のキャラは出ない）。2＋2は「AかBの1個」を候補にし、2個ずつの組み合わせまでは見ない |
| 砂・杯・冠 | 育成候補と聖遺物のページで、メインOPを絞る。空欄なら、いま付けているもの |
| 4+1 | 育成候補の「ほかのセットも出す（4+1）」の初期状態。画面で切り替えられるが、保存はされない |
| 確認済み | 読み込むが、いまは画面に出していない |
| メモ | アプリでは使っていない |

- 使えるセット・メインOP・4+1 は、いまのところ遊ぶ人が上書きできない（表の値で決まる。`docs/ROADMAP.md` 2.7 の「調整弁」）
- 有効OPはキャラに1組。セットによって有効OPを変えることは書けない
- 表の行は、そのキャラがキャラ一覧に入っているときだけ効く（持っていないキャラの行は、入れるまで何もしない）
- 旅人は元素を分けず1行

## 直し方
1. GitHub で `src/builds.csv` を開き、右上の鉛筆（Edit）で直す。GitHub では表の形で見られる
2. 「Commit changes」で `main` に保存すると、GitHub Actions が自動で組み立てて公開する（1〜2分）。公開ページで強制再読み込みすると反映される
   - 書き間違いがあると Actions が失敗（赤い×）になり、公開ページは前のまま。Actions のログに行番号つきで理由が出る
3. 保存する前に確かめたいときや、失敗したときは、Claude に「builds.csv を確かめて」と頼む（中身は `python3 tools/check_builds.py`。書き間違いを行番号つきで教えてくれる）
   - 「会心ダメ」「攻撃%」「熟知」「チャージ」などの略した書き方は、`python3 tools/check_builds.py --fix` で正式な書き方にそろう
4. Excel で開く場合は、文字コード UTF-8 の CSV として読み書きする（ほかの形式で保存すると文字化けする）

## 列
| 列 | 書き方 | 例 |
|---|---|---|
| キャラ | ゲームの日本語名（行を足すときも、この名前で） | 九条裟羅 |
| 有効OP | サブOPを「・」でつなぐ | 元素チャージ効率・攻撃力%・会心率・会心ダメージ |
| 使えるセット | 4セットはセット名だけ。2＋2は「A＋B」、2セットだけ決まっているなら「A＋どれでも」。候補が複数なら「／」でつなぐ | 絶縁の旗印／旧貴族のしつけ |
| 砂・杯・冠 | メインOP。複数OKなら「・」でつなぐ。空欄は「いま付けているもの」 | 炎元素ダメージ・攻撃力% |
| 4+1 | 4セットのキャラで、1か所だけほかのセットを使ってよいなら「○」 | ○ |
| 確認済み | 自分で見直した行に「○」。空欄の行は、持ち主の装備（2026-11-12 の動画）から推測したままのたたき台 | ○ |
| メモ | 自由に | 草原核の型 |

- 有効OPが空欄の行は「初期値なし」（装備からの推測に任せる）
- 持ち主が持っていないキャラは、いったん全員「会心率・会心ダメージ・攻撃力%」にしてある（確認済みは空欄）。使えるセット・メインOPが空欄なら、いま付けているものを使う
- 使える書き方：
  - サブOP：会心率・会心ダメージ・攻撃力%・HP%・防御力%・元素熟知・元素チャージ効率・攻撃力・HP・防御力
  - 砂：HP%・攻撃力%・防御力%・元素熟知・元素チャージ効率
  - 杯：HP%・攻撃力%・防御力%・元素熟知・物理ダメージ・（炎/水/氷/雷/風/岩/草）元素ダメージ
  - 冠：HP%・攻撃力%・防御力%・元素熟知・会心率・会心ダメージ・治癒効果
- キャラ名・セット名の元は `src/scanner/data.js`（聖遺物ビデオスキャナーの表）。新キャラ・新セットはそこに入ってから使える
