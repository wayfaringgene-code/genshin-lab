# 育成の方針の初期値（`src/builds.csv`）

キャラごとに「どの聖遺物を育てる候補にするか」を決める表。**このアプリでの初期値**で、遊ぶ人同士で比べやすくするためのもの。
遊ぶ人が自分の端末で決めた方針（有効OPなど）があれば、そちらが優先される。どちらもないキャラは、いままでどおり装備から推測する。

> まだアプリには組み込んでいない（聖遺物一覧・育成候補を作るときに使う予定。`docs/ROADMAP.md` の 2.7）。今は表を整えておく段階。

## 直し方
1. GitHub で `src/builds.csv` を開き、右上の鉛筆（Edit）で直す。GitHub では表の形で見られる
2. 直したら、Claude に「builds.csv を確かめて」と頼む（中身は `python3 tools/check_builds.py`。書き間違いを行番号つきで教えてくれる）
   - 「会心ダメ」「攻撃%」「熟知」「チャージ」などの略した書き方は、`python3 tools/check_builds.py --fix` で正式な書き方にそろう
3. Excel で開く場合は、文字コード UTF-8 の CSV として読み書きする（ほかの形式で保存すると文字化けする）

## 列
| 列 | 書き方 | 例 |
|---|---|---|
| キャラ | ゲームの日本語名（行を足すときも、この名前で） | 九条裟羅 |
| 有効OP | サブOPを「・」でつなぐ | 元素チャージ効率・攻撃力%・会心率・会心ダメージ |
| 使えるセット | 4セットはセット名だけ。2＋2は「A＋B」、2セットだけ決まっているなら「A＋どれでも」。候補が複数なら「／」でつなぐ | 絶縁の旗印／旧貴族のしつけ |
| 砂・杯・冠 | メインOP。複数OKなら「・」でつなぐ。空欄は「いま付けているもの」 | 炎元素ダメージ・攻撃力% |
| 4+1 | 4セットのキャラで、1か所だけほかのセットを使ってよいなら「○」 | ○ |
| 確認済み | 自分で見直した行に「○」。空欄の行は、持ち主の装備（2026-11-12 の動画）から推測したままのたたき台 | ○ |
| メモ | 自由に | 草原核の型 |

- 有効OPが空欄の行は「初期値なし」（装備からの推測に任せる）
- 使える書き方：
  - サブOP：会心率・会心ダメージ・攻撃力%・HP%・防御力%・元素熟知・元素チャージ効率・攻撃力・HP・防御力
  - 砂：HP%・攻撃力%・防御力%・元素熟知・元素チャージ効率
  - 杯：HP%・攻撃力%・防御力%・元素熟知・物理ダメージ・（炎/水/氷/雷/風/岩/草）元素ダメージ
  - 冠：HP%・攻撃力%・防御力%・元素熟知・会心率・会心ダメージ・治癒効果
- キャラ名・セット名の元は `src/scanner/data.js`（聖遺物ビデオスキャナーの表）。新キャラ・新セットはそこに入ってから使える
