## 1. 図（育てる順番）が何を表しているか

<!-- 持ち主が「別添みたいな図」と呼んでいる図 -->

- **横軸**：効くサブOPに入った強化の回数（0〜45回）。+20の聖遺物1個に入る強化は、はじめ4OPなら9回、はじめ3OPなら8回なので、5部位で全体は40〜45回。そのうち、その型に効くサブOPに入った回数が横軸
- **縦軸**：その回数のときの「いちばん良い配分」を、ステータスごとに積み上げたもの（合計は横軸と同じ回数）
- **縦の点線（断面）**：答えを読み取る回数。いまは30回
- **紫の帯（元素チャージ）**：元素爆発を回すために先に確保する回数（色を薄くしたもの）。絶縁の旗印などでチャージ効率がダメージにも効く型は、濃い色で、必要な分を超えても配る
- **右の薄い所**：そのメインOPと「1行の上限」では、それ以上は入りきらない回数

### 図の作り方（計算の決まり）
1. **1回分の伸び**は平均：会心率 3.305%・会心ダメ 6.6125%・攻撃力% 4.9575%・HP% 4.9575%・熟知 19.815・チャージ効率 5.505%
2. **メインOP**：花はHP 4780、羽は攻撃力 311。砂・杯・冠は候補の中から組み合わせを全部試す
   - 候補（ふつう）：砂＝攻撃力%・熟知・チャージ／杯＝その元素・攻撃力%・熟知／冠＝会心率・会心ダメ・攻撃力%・熟知
   - HPのキャラ（胡桃）は HP% も足す
   - メインOPの値：攻撃力%・HP%・元素ダメージ 46.6%、熟知 186.5、チャージ 51.8%、会心率 31.1%、会心ダメ 62.2%
3. **入る回数の上限**
   - 1つのステータスに入れられるのは「メインOPでない部位の数 × 1行の上限（厳選の現実度）」まで。サブOPは、メインOPと同じステータスの部位には付かないため
   - 1部位に入る効く強化は「5＋効く行の数」回まで（効かない行にも、はじめの1回は入るため）。さらに「効く行の数 × 1行の上限」まで
4. **元素爆発が必須の型**：必要なチャージ効率（下の式）に届くまでのチャージ効率の回数を、先に確保する
5. **メインOPの組み合わせは、それぞれ「その組み合わせで入りきる回数（断面まで）」で比べる**。メインOPを熟知にすると熟知のサブOPが入る部位が減るので、同じ回数で比べると不公平になる
6. **解き方**：効くサブOPが4種類までは全部の配分を数える。5種類以上（胡桃）は、出発点を変えて「2つのステータスの間で何回でも入れ替え、良くなる間は続ける」方法。4種類までのすべての型・組み合わせ・回数（10・20・30・40回）で、全部数える方法と答えが完全に一致することを確かめた（ページの `__check()`）

### 必要なチャージ効率（一期一会のパーティ用に一般化した式）
```
必要なチャージ効率 ＝ (元素爆発のコスト － 固定で戻るエネルギー) ÷ (自分の粒子 ＋ チームからもらうエネルギー ＋ 西風) × 100%
自分の粒子 ＝ 元素スキルの粒子 × (元素爆発のクールタイム ÷ 元素スキルのクールタイム) × 3
```
- 粒子1個は、同じ元素で場にいれば3（いるとみなす）。チームからもらうエネルギーは全キャラ共通の一律の値（いまは25）。西風武器は6（1回の元素爆発までに1回発動とみなす）
- 固定で戻るエネルギー（ウェンティの暴風の目の15など）は、チャージ効率に関係なく入るので先に引く
- 元素爆発を使わない型、エネルギーで撃たない型（マーヴィカの戦意、スカークのエネルギー上限0）は、チャージ効率を考えない

### 全キャラ共通の値（「えいや」で決めるもの。いまの仮の値）
| 値 | いまの値 | 意味 |
|---|---|---|
| 断面 | 30回 | 答えを読み取る、効くサブOPの回数 |
| 1行の上限（厳選の現実度） | 3回 | サブOPの1行に何回まで入るとみなすか。理論上は6回。4回以上入る行は1割ほど |
| チームからもらうエネルギー | 25 | 元素爆発1回分の間に、ほかのキャラからもらうエネルギー（チャージ効率100%のとき） |
| 有効OPに数える線 | 1回以上 | 断面のいちばん良い配分で1回以上入るものを有効OPとする |
| バフ | なし | ベネットなどのバフは入れない（一期一会の前提。需要があれば後で） |

## 2. 箱（キャラ×型ごとに埋める欄）

| 欄 | 何を書くか | 選べるもの・例 |
|---|---|---|
| 役割 | | アタッカー／サブアタッカー／サポーター |
| 技の種類 | 比べる技がどの種類か | 通常攻撃／重撃／元素スキル／元素爆発／反応 |
| 比べる技 | 1発に決める | 「元素爆発の放電」「冥蝶の舞の重撃」など |
| 式の部品：土台 | ダメージが何に比例するか | 攻撃力／HP→攻撃力（胡桃）／チャージ効率→攻撃力（雷電）／熟知（月開花・拡散）など |
| 式の部品：ダメージバフ | 元素ダメージ%などが効くか | 効く（天賦のダメージ）／効かない（月反応・拡散） |
| 式の部品：反応 | | なし／増幅（蒸発・溶解）／超激化／月感電（反応・リサ1人分）／月感電（直接・攻撃力）／月開花（直接・熟知）／拡散 |
| 式の部品：会心 | | あり／なし（拡散など固定の反応） |
| 元素爆発 | 必須か | 必須なら必要なチャージ効率を確保する |
| エネルギー | キャラのデータ | 元素爆発のコスト・クールタイム、元素スキルの粒子・クールタイム、固定で戻るエネルギー |
| 武器 | ★5はモチーフ武器R1、★4は型の代表1つ | 西風かどうか |
| 聖遺物 | 4セット | |
| いつも入れるバフ | 天賦・武器・セットの条件つき効果で「成立する」とみなすもの | |

**比べると消えるもの**（式に入れない）：天賦の倍率（超激化の型を除く）、敵の耐性・防御、増幅の×1.5・×2（全部が反応する前提なら）、月感電の×3、ステータスに比例する上乗せ（戦意・願力など）、全員に同じだけ掛かる倍率（暴風の目の135%、固有天賦の×1.1〜1.7など）

**倍率が消えないとき**：超激化（天賦の倍率に関係なく足される上乗せ）と、反応する割合が1でない増幅は、天賦の倍率と割合が要る

## 5. 型別の式と答え（断面30回・1行3回まで・チーム25）

式の記号：**攻撃力**＝基礎攻撃力×(1＋攻撃力%)＋実数（羽311）、**会心**＝(1＋min(1,会心率)×会心ダメ)、**増幅**＝倍率×(1＋2.78×熟知÷(熟知＋1400)＋反応ボーナス)、**超激化の上乗せ**＝1.15×1446.85×(1＋5×熟知÷(熟知＋1200)＋反応ボーナス)、**月反応の熟知の項**＝(1＋6×熟知÷(熟知＋2000)＋反応ボーナス)、**拡散**＝0.6×1446.85×(1＋16×熟知÷(熟知＋2000)＋反応ボーナス)

## 6. 感度の表（次のスレッド）に必要なこと

### 目的
全キャラ共通の値を「えいや」で決める。値を動かしても答え（メインOP・有効OP）がほとんど変わらないことを確かめ、変わる型だけ印を付ける。予想は「決め方で大きな差は出ない」

### 動かす値と範囲
| 値 | 試す範囲 | いま |
|---|---|---|
| 断面 | 20・30・40回 | 30 |
| 1行の上限 | 3・4回（参考に6回） | 3 |
| チームからもらうエネルギー | 15・25・35 | 25 |
| 有効OPに数える線 | 1回以上／外しても1%以内で済むなら外す | 1回以上 |

### 記録するもの（キャラ×型×値の組ごと）
- メインOP（砂／杯／冠）
- 有効OP（1回以上入るもの）と、それぞれの回数
- 必須のチャージ効率の回数
- 1%以内の幅（`proto/subop-guide.html` の `tol` と同じ考え方）。「ほぼ決まり」か「どちらでもいい」か
- 入りきらないとき、その回数（拡散サポートのように効くサブOPが少ない型）

### ここまでで分かっていること（感度を見るときの注目点）
- **会心の上限**：1行3回だと、会心率冠なら会心率12回・会心ダメ15回で頭打ち。30回の断面では、会心で戦う型の答えが似てくる。型の違いは、メインOPとチャージ効率の回数、熟知・攻撃力%・HP%の少しの回数に出る → 断面20回、1行4回で差が広がるかを見る
- **チームのエネルギー**：リサ・香菱・雷電で、砂がチャージ効率になるかどうかを左右する。前に（自分の粒子を15で数えていたとき）リサの超激化は必要な量229%に届かず入りきらなかった → チーム15では入りきらない型が出るはず
- **蒸発と溶解**：全部が反応する前提なら同じ答え。箱を減らせる
- **熟知だけの型**：入る回数の上限がそのまま答え。断面を変えても変わらない

### 作り方の案
- `proto/types.html` の計算（`sol`・`compute`）に、値を外から渡して回すだけで表が作れる。全部の組み合わせは 3×2×3＝18 通り×18型。胡桃は入れ替えの方法なので、1回あたり数秒かかる
- 有効OPに数える線の「外しても1%以内」は、そのステータスを0回にして（ほかに配り直して）いちばん良い値との差を見る

### 未確定・目安のもの
- ウェンティ：暴風の矢の倍率は画面に出ていない（基準の技を暴風の矢1本にしているので消える）。魔導秘儀の+50%はウェンティが場にいて拡散するとみなした
- 雷電：元素スキルの粒子は目安（4個）。草薙の「元素爆発の後 チャージ効率+30%」はいつも入れている
- 胡桃：HP50%以下（固有天賦・護摩）とみなした。燃え盛る炎の魔女の2セットの上乗せは元素スキル1回分
- 暁を告げる歴史：攻撃し続ければ上限の60%のままとみなした
- フリンズ・マーヴィカ・スカーク・ネフェル：チャージ効率は考えていない（フリンズ・ネフェルは未確認）
- リサの月感電：リサ1人分で比べている（順位の掛け率は消えるとみなした）
- ベネットなどのバフ：入れていない

## 7. キャラ・型を足すとき（手順）

1. **型を決める**：持ち主と相談して、キャラごとに1つ〜数個。比べる技は1発に決める（技の種類も）
2. **数字をそろえる**：`npm pack genshin-db`（展開して `python3 -I` で読む）
   - キャラ：`stats.characters.<key>` と `curve.characters["90"]` で Lv90 の基礎攻撃力・HP、突破のステータス
   - 天賦：`data.Japanese.talents.<key>` の説明、`stats.talents.<key>.combatN.paramM[天賦Lv-1]` の倍率・クールタイム・コスト
   - 武器：`stats.weapons.<key>` と `curve.weapons["90"]`、効果は `data.Japanese.weapons.<key>.r1`
   - セット：`data.Japanese.artifacts.<key>.effect2Pc / effect4Pc`
3. **式を確かめる**：gcsim（`git clone --depth 1 --filter=blob:none --sparse https://github.com/genshinsim/gcsim`）の `internal/characters/<キャラ>`（攻撃の種類・ICD・粒子の `QueueParticle`）、`internal/weapons`、`internal/artifacts`、`pkg/enemy/damage.go`（増幅・月反応）、`pkg/core/combat/reaction.go`（激化・拡散）、`pkg/reactable/*.go`（月感電・星反応）
4. **箱を埋める**：`proto/types.html` の `CHARS` にキャラ（基礎の値・エネルギー）と型（`parts`・`weapon`・`set`・`add`・`addNote`）を足す。武器・セットが辞書になければ `WEAPON`・`SET` に足す。新しい式の形なら `dmgOf`・`fmlOf`・`varsOf`・`partsTxt` に足す
5. **確かめる**：ページの `__check()`（効くサブOPが4種類までの型で、全部数える方法と入れ替えの方法の答えが一致するか）。式は1つ手で計算して照らす
6. **持ち主と話す**：断面の答えが感覚と合うか
